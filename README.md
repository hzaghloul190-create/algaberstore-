# ال جابر للزي الشرعي — متجر إلكتروني

واجهة متجر عربية RTL بتصميم فاخر داكن/ذهبي، باستخدام React + Vite + Framer Motion.

## متطلبات التشغيل

- Node.js 18+
- npm 9+
- Visual Studio Code

## 1) تثبيت المشروع

```bash
npm install
```

## 2) تشغيل الموقع محليًا

```bash
npm run dev -- --host 0.0.0.0 --port 4173
```

ثم افتح الرابط التالي في المتصفح:

- http://localhost:4173/

## 3) إعداد قاعدة البيانات

هذه النسخة تستخدم بيانات تجريبية محفوظة داخل المتصفح عبر localStorage لأغراض التطوير السريع.

لإعداد بيئة أكثر احترافية لاحقًا، يمكن ربطها بـ Supabase أو backend حقيقي، مع الجداول التالية:

- products
- orders
- reviews
- settings
- customers

## 4) إعداد Storage الصور

- يمكن رفع الصور إلى Storage في Supabase أو backend حقيقي.
- في النسخة الحالية، الصور المدمجة داخل المشروع تكون كـ demo assets placeholder.

## 5) إعداد المتغيرات البيئية

أنشئ ملف .env بناءً على ملف .env.example:

```bash
copy .env.example .env
```

المتغيرات الأساسية:

- VITE_ADMIN_PASSWORD=omar777
- VITE_SHIPPING_DEFAULT=45
- VITE_PAYMENT_NUMBER=01033277866
- VITE_FACEBOOK_URL=https://www.facebook.com/profile.php?id=100094703921655

## 6) تشغيل لوحة الإدارة

- اضغط زر الإدارة في شريط الموقع.
- استخدم كلمة المرور الافتراضية في ملف .env أو القيمة الحالية:
  - omar777

## 7) تغيير كلمة المرور

تغيير كلمة المرور يتم عبر متغير البيئة:

```env
VITE_ADMIN_PASSWORD=كلمة_جديدة_هنا
```

## 8) النشر

لبناء النسخة الإنتاجية:

```bash
npm run build
```

ثم قم بنشر مجلد dist على أي استضافة مثل:

- Netlify
- Vercel
- Firebase Hosting
- GitHub Pages

## مميزات المشروع الحالية

- تصميم عربي RTL فاخر ومتجاوب
- Hero Section أنيميشن
- أقسام وعرض منتجات
- البحث والفلاتر
- السلة والطلب
- لوحة إدارة للتعامل مع المنتجات والطلبات

## ملاحظات أمان

- لا تضع كلمة المرور الفعلية في LocalStorage.
- في الإنتاج، استخدم auth server-side أو Supabase Auth.
- يمكن توسيع المشروع لاحقًا بإضافة:
  - كوبونات الخصم
  - شحن حسب المحافظة
  - إشعارات
  - أكثر من مدير
  - لوحة تقارير
  - منتجات مفضلة
